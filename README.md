# Snack Machine

> A fun and interactive Snack Machine game simulation — purchase, dispense, manage snacks and reels in a virtual vending-machine environment.

---

## 🎮 Overview

The game-snackmachine project provides a simulated vending-machine experience: players insert virtual coins or tokens, select snack items, watch the machine dispense, manage inventory, and aim for high-score efficiency.  
Built with Javascript, it’s ideal for showcasing your interactive game design, physics/animation work, UI logic, and the blending of gamification with a vending machine-style UI.

---

## 🧩 Features

- 🪙 Insert coins / tokens and select snack items  
- 🎯 Dispense animation and sound effects  
- 📦 Inventory management of snack products (stock, refill, restock)  
- 💡 Score tracking based on successful dispenses vs. failures  
- 🔁 Retry or reset mechanics, maybe mini-game or challenge mode  
- 🎨 UI interface mimicking a real-life snack machine with interactive buttons  
- 📱 (Optional) Responsive or 2D/3D presentation suitable for web/desktop/mobile  

---

## ⚙️ Tech Stack

- **Unity** – Game engine  
- **C#** – Scripting and game logic  
- **Unity UI / Animator** – Interface and animations  
- **Audio** – Coin insert, button press, snack dispense sounds  
- **(Optional)** Local save data via PlayerPrefs or simple file for best scores  
- **Deployment** – WebGL build, Windows/Mac build or mobile (optional)
